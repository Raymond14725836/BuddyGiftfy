# BuddyGiftfy

เว็บไซต์ร้านของขวัญ - รายงานสรุปสำหรับ Portfolio

รัฐพงศ์ คูสกุลธรรม | โครงการกลุ่ม 5 คน | Section 2, Group 8

HTML / CSS JavaScript Node.js 22+ MySQL 8 Figma 

### 1. วัตถุประสงค์และขอบเขต

โครงการเว็บไซต์สำหรับเลือกซื้อของขวัญ ค้นหาและดูสินค้า จัดการตะกร้า สร้างคำสั่งซื้อ และแนบหลักฐานโอนเงิน พร้อมหน้าผู้ดูแลสำหรับสินค้า หมวดหมู่ บัญชีผู้ดูแลและคำสั่งซื้อ เป็นระบบสาธิตของโครงการมหาวิทยาลัย

### 2. บทบาทที่ผมมีส่วนร่วม

- ร่วมออกแบบ UI/UX ด้วย Figma
- ทดสอบการทำงานของบางฟังก์ชันด้วยตนเอง
- ร่วมจัดทำคู่มือผู้ใช้และสไลด์ประกอบการนำเสนอ

รายงานฉบับนี้ระบุส่วนที่ผู้สมัครยืนยันว่าได้มีส่วนร่วม ไม่อ้างว่าเป็นผู้พัฒนาทั้งระบบหรือเป็นผู้เขียนชุดทดสอบทั้งหมดเพียงคนเดียว เครดิตโครงการยังเป็นของสมาชิกทีมทั้ง 5 คนตาม README

### 3. โครงสร้างระบบ

Browser / HTML

› Frontend :3000

› API :3001

› MySQL :3306

| ส่วน | รายละเอียด |
| --- | --- |
| Frontend | HTML แยกหน้า CSS และ JavaScript controllers; Node.js ให้บริการไฟล์หน้าเว็บและส่งต่อ /api |
| Backend | Node.js JSON API ตรวจข้อมูลและสิทธิ์ก่อนเข้าถึง MySQL ผ่าน mysql2 |
| ข้อมูล | SQL ตัวอย่างสำหรับติดตั้งใหม่ และ migrations ของโครงการ |
| บริการภายนอก | Frankfurter ใช้เทียบงบเงินบาทเป็นสกุลอื่น ยอดชำระในระบบยังเป็นเงินบาท |

### 4. ภาพรวมความสามารถ

- ลูกค้า: เลือกสินค้า ตะกร้า คำสั่งซื้อ และอัปโหลดหลักฐานชำระเงินสาธิต
- ผู้ดูแล: จัดการสินค้า หมวดหมู่ สมาชิกผู้ดูแล ตรวจสลิป และสถานะจัดส่ง

เอกสารฉบับนี้สรุปจากซอร์สโค้ดและเอกสารที่มีอยู่เพื่อประกอบการสมัครฝึกงาน ไม่ใช่รายงานส่งอาจารย์ต้นฉบับ และไม่ได้รันทดสอบระบบใหม่ในการจัดทำรายงานครั้งนี้

### 9. การติดตั้งแบบย่อ

- ติดตั้ง Node.js 22 ขึ้นไป และ MySQL Server 8 ตามคู่มือ
- นำเข้า sec2_gr8_database.sql ใน MySQL สำหรับสาธิต ไม่ใช้ฐานข้อมูลจริงที่มีข้อมูลอยู่แล้ว
- ติดตั้ง dependencies ของ backend และคัดลอก .env.example เป็น .env ตั้งค่าฐานข้อมูลของเครื่องตนเอง
- เปิด API ที่พอร์ต 3001 และ frontend ที่พอร์ต 3000 แล้วเข้าหน้า http://localhost:3000

```sh
# Backend
cd sec2_gr8_ws_src
npm ci
npm start

# Frontend - separate terminal
cd sec2_gr8_fe_src
node server.js
```
