# BuddyGiftfy - ส่วนหน้าบ้าน

ส่วนนี้ประกอบด้วยหน้าเว็บ HTML, CSS, JavaScript รูปภาพ และฟอนต์ ทั้งหน้าร้านและหน้าผู้ดูแล การอ่านและเขียนฐานข้อมูล MySQL ทำผ่าน [บริการส่วนหลังบ้าน](../backend/README.md)

## เปิดใช้งาน

ใช้ Node.js 22 ขึ้นไป และเปิด MySQL กับบริการ API ตาม [คู่มือติดตั้ง](../docs/INSTALLATION.md) ก่อน จากนั้นเปิดหน้าต่างคำสั่งในโฟลเดอร์ `frontend` แล้วรัน:

```sh
node server.js
```

เปิด [หน้าร้าน](http://localhost:3000/) หรือ [หน้าเข้าสู่ระบบผู้ดูแล](http://localhost:3000/admin/login)

ไม่ต้องติดตั้งแพ็กเกจในโฟลเดอร์นี้ เพราะเซิร์ฟเวอร์ใช้โมดูลที่มีมากับ Node.js

## โครงสร้างไฟล์

| ตำแหน่ง | หน้าที่ |
| --- | --- |
| `public/*.html` และ `public/admin/*.html` | โครงหน้าเว็บ เมนู แบบฟอร์ม และแม่แบบสำหรับรายการซ้ำ |
| `public/js/pages/` | โค้ดควบคุมการทำงานของแต่ละหน้า |
| `public/js/common.js` | อ่านข้อมูลการเข้าสู่ระบบ ตรวจสิทธิ์ และเรียกข้อมูลของหน้า |
| `public/js/api.js` และ `public/js/app.js` | เรียกข้อมูล JSON และจัดการพฤติกรรมร่วม เช่น แบบฟอร์ม เมนู และการอัปโหลด |
| `public/js/shared/` | โค้ดใช้ร่วมกันสำหรับแบบฟอร์ม รูปภาพ คำสั่งซื้อ และบริการเทียบสกุลเงิน |
| `server.js` และ `page-paths.js` | ส่งไฟล์หน้าเว็บ เปลี่ยนเส้นทาง URL เดิม และส่งต่อคำขอ API หรือไฟล์อัปโหลด |

หน้าแรกใช้ URL `/` โดยอ่านไฟล์ `public/index.html` ส่วน `/index.html` จะเปลี่ยนเส้นทางไป `/` พร้อมเก็บค่าคำค้นใน URL หน้าอื่นมีไฟล์ HTML ของตัวเอง รวม 39 หน้าเมื่อนับหน้าแจ้งข้อผิดพลาด 404

## การเชื่อมต่อส่วนหลังบ้าน

เบราว์เซอร์เรียก `/api/...` ผ่านพอร์ตหน้าบ้าน และ `server.js` ส่งต่อไปยัง `http://127.0.0.1:3001` ตามค่าเริ่มต้น

| ตัวแปร | หน้าที่ |
| --- | --- |
| `FRONTEND_PORT` | เปลี่ยนพอร์ตหน้าบ้าน |
| `API_UPSTREAM` | เปลี่ยนที่อยู่บริการหลังบ้านที่เซิร์ฟเวอร์หน้าบ้านส่งคำขอไป |
| `API_ORIGIN` | ใช้เฉพาะกรณีที่ต้องการให้เบราว์เซอร์เรียกหลังบ้านโดยตรง |

ตั้งตัวแปรเหล่านี้ในสภาพแวดล้อมตอนเปิดหน้าบ้าน ส่วน `FRONTEND_ORIGIN` ของหลังบ้านต้องตรงกับที่อยู่หน้าเว็บที่ผู้ใช้เปิดจริง

หากเปิดผ่านเซิร์ฟเวอร์ตัวกลาง เช่น Nginx Proxy Manager ให้ส่งทั้งคำขอหน้าเว็บและ `/api/` มาที่เซิร์ฟเวอร์หน้าบ้าน
