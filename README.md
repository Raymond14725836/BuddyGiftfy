# BuddyGiftfy

เว็บไซต์ร้านของขวัญสำหรับโครงการวิชา ITDS242 พัฒนาเป็นทีม 5 คน (Section 2, Group 8) รองรับการค้นหาสินค้า ตะกร้า การสั่งซื้อ และการจัดการร้าน

## ส่วนที่ผมรับผิดชอบ

**รัฐพงศ์ คูสกุลธรรม (Rattapong Koosakultham)**

- ร่วมออกแบบ UI/UX ด้วย Figma
- ทดสอบการทำงานของบางฟังก์ชันด้วยตนเอง
- ร่วมจัดทำคู่มือผู้ใช้และสไลด์นำเสนอ

โครงการนี้เป็นผลงานกลุ่ม รายการความสามารถด้านล่างอธิบายระบบโดยรวม

## ความสามารถหลัก

- ค้นหาสินค้าตามคำค้น หมวดหมู่ และช่วงราคา
- ดูรายละเอียดสินค้า เพิ่มสินค้าลงตะกร้า และสร้างคำสั่งซื้อ
- แนบหลักฐานการชำระเงินสาธิตให้ผู้ดูแลตรวจสอบ
- จัดการสินค้า หมวดหมู่ บัญชีผู้ดูแล และสถานะคำสั่งซื้อ
- เทียบงบของขวัญเป็นสกุลเงินอื่นผ่าน Frankfurter API

## เทคโนโลยี

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js
- **Database:** MySQL
- **เครื่องมือออกแบบ:** Figma

## การทดลองใช้งาน

ระบบต้องติดตั้งและรันในเครื่อง โดยใช้ Node.js 22 ขึ้นไป และ MySQL Server 8 ปัจจุบันยังไม่มีลิงก์เดโมออนไลน์ถาวร

1. นำเข้าฐานข้อมูลตัวอย่างจาก `database/sec2_gr8_database.sql`
2. ติดตั้ง dependencies และตั้งค่า `.env` ของ Backend
3. เปิด Backend ที่พอร์ต 3001 และ Frontend ที่พอร์ต 3000
4. เปิด `http://localhost:3000`

อ่านคำสั่งติดตั้งและบัญชีสาธิตใน [คู่มือติดตั้ง](docs/INSTALLATION.md)

การชำระเงินเป็นขั้นตอนสาธิตและตรวจสอบโดยผู้ดูแล ไม่มีการติดต่อธนาคารอัตโนมัติ โปรดใช้ข้อมูลและภาพสลิปตัวอย่างในการทดลอง
